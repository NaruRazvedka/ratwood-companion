Ratwood source and artwork

The guide uses Rotwood-Vale/Ratwood-2.0 for item definitions, recipes, mechanics and permitted repository sprites. The guide displays its pinned revision and review date. Repository history and the older Ratwood Keep source provide historical context.

Copyright remains with the original authors and contributors. Application code and adapted parser code are distributed under AGPL-3.0-or-later. Game assets retain their upstream licenses, including CC BY-SA 3.0 where specified. Sprite crops are derived from the repository sheets; extraction and license records are retained with the source. Per-file exceptions take precedence.

The public package excludes proprietary asset directories, cached client-pack artwork with unestablished redistribution rights, and the Pterra font. Its preview therefore uses a system serif fallback. See the workshop notices and guide notices for details.

Organization and interface

Caffezinpowm’s projects, including barman-dumont, provided organizational inspiration for compact catalogues and expandable preparation branches. Their content is unrelated to Ratwood. No source code or artwork from those projects is copied into this companion.

Interface category symbols identify food, liquids, equipment and missing artwork. They are guide icons, not substitutes presented as game sprites.

Accuracy and privacy

Source inspection confirms what a pinned revision defines. It does not confirm the live server’s deployed revision, map availability or every runtime interaction. Recipe conflicts and missing conditions remain visible where they affect use. Release notes record reviewed changes.

Workshop drafts and guide bookmarks stay in your browser. They are not uploaded to this project. Exported draft backups may contain private character text; keep them private. Moving between a local file and the hosted website requires export and import because browser storage is separate.
