# Field guide attribution

## Ratwood source

The primary game reference is [Rotwood-Vale/Ratwood-2.0](https://github.com/Rotwood-Vale/Ratwood-2.0). The supplemental current-source snapshot is revision `2d61e02c69520dacb0f4edc1d269395713cbeafb`, reviewed 2026-11-17; its file hashes and changes are recorded in `sources/ratwood-current/manifest.json`.

Earlier indexed recipes, item descriptions, properties, native fixtures and sprites retain their recorded revisions. In particular, the earlier Ratwood 2.0 reference uses `80907df21ed15bde91106da41ce82e6ac6c40069`, and historical Ratwood Keep references use `74f55d70294af6ac3650d7e2839ef70b3ce7db0d`. A new supplemental pin does not upgrade those older records by association.

Copyright remains with the respective upstream contributors. Source files retain their original AGPL/GPL notices as applicable. Companion application code follows **AGPL-3.0-or-later**, reproduced in the parent `LICENSE`. Source-backed facts and adapted descriptions retain their provenance in the source records; no DM expressions are executed to generate descriptions.

## Repository artwork

Public sprites are derived from permitted Ratwood repository DMI icon states. Their extraction records identify original paths, states and pinned revisions. Source sheets and applicable upstream notices accompany the retained artwork records. The Ratwood 2.0 README specifies CC BY-SA 3.0 for assets unless otherwise indicated; inherited and per-file exceptions remain applicable. Cropping does not remove the original authors' rights or attribution requirements.

Do not apply one blanket artwork license to files carrying an exception. Proprietary artwork directories are excluded. Runtime tinting, compositing and inherited states can differ from the reference crops. Guide category icons are interface symbols and are not represented as extracted game sprites.
